Privacy

Last updated September 19, 2026

spendtron is a sole proprietorship of Joe Swanson in Bozeman, Montana. Support: joe@swantron.com.

You connect a GitHub App (spendtron-app) with read-only Actions and Metadata permissions on the repositories you choose. We use that installation to list those repos and sample recent workflow runs so we can rank them by compute. We do not request access to source code, secrets, or write permissions. You can uninstall the App from GitHub at any time.

After install we issue an API key. We store only a SHA-256 hash of that key, plus the GitHub installation id and account login, in Postgres (Neon). The raw key is shown once. If you rotate it, the previous hash is replaced.

If you subscribe ($99/mo), Stripe processes the card and stores billing email. We store Stripe customer and subscription ids so we can unlock audits while the subscription is active and so you can open the Stripe billing portal. We do not sell GitHub or billing data.

GoatCounter records page views on spendtron.com (path, referrer, country, device). That is not a marketing pixel network.

To delete an installation row or billing identifiers, uninstall the GitHub App and email joe@swantron.com.
