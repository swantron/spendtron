How GitHub Actions is billed

  • Per job, rounded up. Each job is billed in whole minutes. A 10-second lint job costs a full minute, and a matrix of 12 such jobs costs 12.
  • At the runner's own rate. Linux 2-core is $0.006 a minute, Windows $0.010, macOS $0.062. Larger runners go up to $0.552.
  • Included compute comes off first. Free and Free-for-orgs plans include $12 a month, Pro and Team $18, Enterprise Cloud $300. It's a dollar amount, so it covers far fewer macOS minutes than Linux.
  • Public repositories don't pay for standard runners. Larger runners are billed there too.
  • Self-hosted runners don't appear on GitHub's compute bill.

The full rate table is in the runner pricing guide. Storage for artifacts and caches is billed separately and isn't included here.

Where to find your numbers

Run counts and durations are on each workflow's page under the Actions tab. For a month of real data, download the detailed usage report from your billing settings. This guide walks through it, and the homepage turns it into a chart.

Want the real numbers instead of estimates?

Load GitHub's detailed usage report on the spendtron homepage for a chart of cost by workflow and runner. It's read in your browser and not uploaded. Or connect the GitHub App to price every job from real runs and get the fixes as a pull request. Both are free.
