Free GitHub Actions cost tools

Four small tools for working out what GitHub Actions costs and where it goes. No sign-up. The calculators run in your browser.

Workflow cost checker

Paste a workflow file and see what makes it expensive, with a patched copy.

Actions cost calculator

Runs, jobs, and minutes in; monthly bill out, at every runner's real rate.

Self-hosted break-even

Is running your own runner cheaper once machine and upkeep are counted?

Larger runner calculator

Does a 4-, 8-, or 16-core runner finish fast enough to pay for itself?

Which one to start with

  • You have a workflow that feels slow or expensive: paste it into the workflow cost checker.
  • You're budgeting, or a bill surprised you: the cost calculator turns runs and minutes into dollars.
  • You're deciding whether to run your own runners: the self-hosted break-even counts the machine and the upkeep.
  • Someone wants a bigger runner: the larger runner calculator shows how much faster the job has to get to break even.

Want the real numbers instead of estimates?

Load GitHub's detailed usage report on the spendtron homepage for a chart of cost by workflow and runner. It's read in your browser and not uploaded. Or connect the GitHub App to price every job from real runs and get the fixes as a pull request. Both are free.
