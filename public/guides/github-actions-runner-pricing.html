GitHub Actions runner pricing, every SKU

GitHub bills Actions by the minute, at a rate set by the runner a job lands on. The rate spread is wide: the cheapest hosted runner is $0.002 a minute and the most expensive is $0.552. Which runner your jobs use matters more than almost anything else in the workflow file.

How a minute is counted

  • Per job, rounded up. GitHub rounds each job's minutes up to the next whole minute. Eight 10-second jobs bill 8 minutes, not 2. A workflow that fans out into many tiny jobs pays the rounding on each one.
  • Parallel jobs add up. Ten jobs running side by side for 5 minutes each bill about 50 minutes, even though the run finished in 5.
  • No OS multiplier. Each minute is charged at its runner's own rate: $0.010 for a Windows minute, $0.062 for a macOS minute.

What each plan includes

Included compute is a dollar amount per month, spent at the runner's own rate. On the 2-core Linux runner, $300 covers 50,000 minutes. On macOS, the same $300 covers under 5,000.

PlanArtifact storageIncluded compute / month
GitHub Free500 MB$12
GitHub Pro1 GB$18
GitHub Free for organizations500 MB$12
GitHub Team2 GB$18
GitHub Enterprise Cloud50 GB$300

On Team and Enterprise Cloud, larger runners can draw from included compute too. Every plan gets 10 GB of Actions cache per repository.

If a month's Actions usage fits inside those numbers, the invoice line is $0, and tuning workflows saves time, not money. The detailed usage report shows which case you're in.
