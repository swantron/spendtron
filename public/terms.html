spendtron sells a read-only GitHub Actions cost ranking. You install the GitHub App, get one free audit per connected org, then $99/month via Stripe for ongoing audits. The charge on your statement is SPENDTRON.

The audit samples recent workflow runs (up to 100 per repo) and estimates cost at GitHub's private Ubuntu per-minute rate. It is a ranking of sampled compute, not a replica of GitHub's invoice. Public repos bill $0 at GitHub; the estimate still uses the private rate so the ranking is comparable.

spendtron does not push code, open pull requests, or change workflow files. Rankings are information. You apply any fixes yourself.

Cancel anytime through the Stripe billing portal (linked after Checkout, or from the receipt email). Digital goods: if Checkout charged you and audits did not unlock, email joe@swantron.com with the GitHub org name before disputing the charge.
