How it works

  1. Connect GitHub. Install the app on the org or repos you choose. It asks for two read-only permissions.
  2. Save your API key. It's shown once after install. Add it as a bearer token in your MCP client, or keep it for direct calls.
  3. Run the audit. Call the check_actions_cost tool. No arguments needed, your key identifies your org.
  4. Read the ranking. Workflows and repos ordered by compute cost, biggest offenders first. You apply any fixes yourself.

What it can and can't touch

  • Read-only. Actions: read and Metadata: read. It can't see or change your code, secrets, or settings.
  • Scoped by you. It only reads the repos you select at install time, and you can uninstall from GitHub at any time.
  • Rankings, never pushes. It does not open pull requests or edit workflow files.
