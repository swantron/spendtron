Or run it in the repo

A composite action writes the same ranking to the job summary and keeps one comment updated on the pull request, using the workflow's own token. No spendtron account.

permissions:
  actions: read
  pull-requests: write
steps:
  - uses: swantron/spendtron/github-action@main

What the pull request will and will not change

  • It will apply a timeout sized above your slowest run, cancel-in-progress for superseded pull-request runs on workflows that don't deploy, and a short public-repo job moving off a larger Linux runner.
  • It will describe missing path filters, a matrix that multiplies the bill, a duplicate push and pull_request trigger, and a macOS runner with no Apple toolchain. Those change which jobs run, so they're written up for you to decide.
  • It will not touch a workflow that looks like a deploy, or open a second pull request while one is still open.
